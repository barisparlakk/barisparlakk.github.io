Projects

Seyir

An autonomous driving stack for Turkish traffic, built from scratch in CARLA 0.9.15.

  1. Perception

    YOLOv11n detects objects, UFLD-v2 finds lanes, Depth-Anything-V2 estimates depth. LiDAR projection fuses them into a 100×100 occupancy grid.

  2. Prediction

    A SocialTransformer forecasts several possible trajectories for every road user.

  3. Planning

    Global A* sets the route, a behaviour state machine picks the manoeuvre, and PPO learns the local decisions.

  4. Control

    An MPC planner in CasADi and IPOPT returns commands in 50 ms or less.

Written in Python and C++ with PyTorch, FastAPI, React and Docker.

DeepDerm

Real-time acne detection and remote treatment tracking.

A YOLOv11 model finds lesions in patient photos and grades severity on the Hayashi scale. Doctors review cases in a web panel while patients log their progress in a mobile app.

Trained on data prepared in Roboflow; served by FastAPI and Spring Boot over PostgreSQL, with React and React Native clients.

TurkRAG

Question answering over Turkish documents with no cloud dependency.

Retrieval combines BM25 keyword search with FAISS vector search, and generation runs locally through Ollama, so sensitive documents stay on your own hardware and within KVKK rules.

Python, LangChain, Sentence-Transformers and FastAPI.
